# たなべ式計算道場 コンセプト

## 中心となる考え方

たなべ式計算道場が目指すのは、単なる計算スキルの獲得ではない。

計算力の背景にある「数感覚」を、トレーニングによって育てる。

## 数感覚の定義

数を単なる記号ではなく、その性質・構造・ほかの数との関係を含めて、多面的・立体的に捉える力。

例えば24を見たとき、3や8の倍数であること、6×4や3×8、20+4、30-6など複数の姿を持つことが自然に見える状態を目指す。

## 3つのアプローチ

1. 暗算力トレーニング — 数を操作する土台をつくる
2. 倍数判定トレーニング — 数の性質・構造を知り、数の世界を縦に深める
3. 計算の工夫トレーニング — 数同士の関係や組み合わせを通じて、数の世界を横に拡げる

3つは初級・中級・上級ではない。相互に行き来することで、数感覚と計算力をスパイラルに育てる。

## 教材思想

- 単調な反復だけに頼らない。
- 大量演習だけに頼らない。
- 数感覚を生まれつきのセンスで片付けない。
- 数に触れ、数を動かし、数の性質・構造・関係をさまざまな角度から見る経験を重視する。
- スキルの暗記ではなく、「こうも見える」「こう変えられる」と自然に感じられる世界を広げる。


## たなべ式の核 — 3方向を行き来する

たなべ式の本質は、暗算・倍数判定・計算の工夫を個別のテクニックとして習得することではない。

- 暗算力トレーニング — **数を動かす**
- 倍数判定トレーニング — **数を深く見る**
- 計算の工夫トレーニング — **数の見方を横に拡げる**

実際の計算ではこの3方向が統合される。

例えば `48×25÷6` では、48が6で割れることを見る（深く見る）、掛ける前に割り8を2×4と見る（横に拡げる）、48÷6や4×25を処理する（動かす）という複数の力が連続して働く。

重要なのは、すべての問題に3要素を無理に当てはめることではない。計算ごとに必要な見方は異なる。**必要な力を自然に行き来できる状態そのものが数感覚である**、というのが教材設計上の中心思想である。

## この思想をどこで表現するか

### トップページ

3カテゴリーの入口として、必ず次の対応を短く示す。

- 暗算力トレーニング｜数を動かす
- 倍数判定トレーニング｜数を深く見る
- 計算の工夫トレーニング｜数の見方を横に拡げる

トップでは詳細を説明しすぎず、3方向の存在を直感的に伝える。

### 「たなべ式計算道場とは？」ページ

数感覚の定義、24の具体例、3方向モデル、3つを行き来する意味をまとまったストーリーとして説明する。サイトの思想を理解したい利用者の主要な参照先とする。

### 各カテゴリーページ

カテゴリー名に副題を併記し、そのカテゴリーが数感覚のどの方向を鍛えるのかを明示する。

### 計算の工夫 — 土台編

副題は **「見方を学ぶ」**。

実践編で再利用する少数の基本的な見方を扱う。既存7講義は固定された完成形とみなさず、実践編との対応を見ながら必要に応じて再構成する。

### 計算の工夫 — 実践編

副題は **「見方を使う」**。

各実践講義には「使っている見方」のタグを付け、該当する土台講義へ戻れるようにする。土台講義側にも、その見方を使う実践講義へのリンクを置く。**土台 ⇄ 実践を双方向にする。**

実践講義では、必要な場合に「頭の中では何が起きている？」等のセクションを設け、暗算・倍数判定・計算の工夫が実際の一つの計算の中でどう連携するかを可視化する。

ただし3カテゴリーを毎回機械的に登場させない。その計算で実際に使われている力だけを示す。

## UI・導線として守ること

- 抽象原理から具体例へ進む一方向の教材にしない。
- 実践から土台へ戻れるようにする。
- 土台から関連実践へ進めるようにする。
- カテゴリーをまたいで関連講義へ進める場合も、学習上の関連性が明確なときだけリンクする。
- 「関連記事」ではなく、**なぜ関連するのか**が分かるラベル・短い説明を添える。


## トップページ Hero（確定）

トップページでは教材思想そのものではなく、保護者が求める結果を先に提示する。

表示階層:

1. Eyebrow: `TANABE METHOD`
2. Main copy: `数を速く正確に処理する`
3. Subtitle: `計算スキル × 数の感覚`
4. Description: `中学受験算数に必要な計算力を身につけます`

「数感覚」「立体的に見る」などの教材思想をHeroの主訴求にはしない。それらは目的ではなく、計算力を身につけるための手段・内部原理として扱う。詳細は「たなべ式計算道場とは？」で説明する。

## 実践編の位置づけと循環モデル

計算の工夫・実践編は、土台編の確認問題集でも、順番に履修するカリキュラムでもない。**具体的なTipsを通じて「計算の工夫」を体感する場**とする。

Tipsそのものの暗記ではなく、同じ数や式にも複数の見方・処理方法があることを経験し、「数の見方を横に拡げる」ことが目的である。

暗算・倍数判定・計算の工夫は並行して磨く。暗算は数を動かす力、倍数判定は数を深く見る力、計算の工夫は数の見方を横に拡げる力を担う。これらは一方向ではなく相互に作用する。

したがって学習モデルは `土台 → 実践` ではなく **`土台 ⇄ 実践`**、さらに **`暗算 ⇄ 計算の工夫 ⇄ 倍数判定`** という往復・循環を基本とする。

## 総合カリキュラムとの責務分離

暗算・倍数判定・計算の工夫を、いつ、どの順番で、どう組み合わせて学ぶかは、将来別途設計する**総合カリキュラム**の責務とする。

各トレーニングカテゴリーは「何を学べるか」を提供するコンテンツ群であり、総合カリキュラムは「それらをどう行き来するか」を設計する。

そのため実践Tips一覧には厳密な履修順序を持たせず、利用者は気になるTipsから取り組める。

## 倍数判定トレーニング「実践編」の位置づけ

実践編は倍数判定そのものを反復するドリルではない。**いつも解いている算数問題の一連の解法の中で、倍数判定を使うと処理が簡単になることを体感する場**とする。

基本編で「判定方法という道具」を学び、実践編では普通の問題を解く途中でその道具が役立つ瞬間を経験する。

基本の体験は `普通の問題 → 判断や計算が必要 → 普通に計算しても解ける → 倍数判定に気づく → 面倒な処理を減らす → 問題を最後まで解く` とする。

問題文で安易に「倍数判定を使いましょう」と指示しない。倍数判定を使わなくても解ける問題の中で「ここで使うと便利だ」と分かることに価値がある。

MVPでは実践編を次の2テーマに絞る。

1. **割り切れるかをサッと見抜く**
2. **サッと約分する**

各テーマでは性格の異なる2つ程度の問題を扱う。「サッと通分する」は有用な候補だが、最小公倍数など別の能力が大きく関わるためMVPでは扱わない。

### 他カテゴリーとの接続

同じ問題を複数カテゴリーから扱ってよい。例えば `48×25÷6` では、倍数判定は「48が6で割り切れることに気づく」、計算の工夫は「気づいたら先に割って数を大きくしない」、暗算は「48÷6や8×25を軽く処理する」という異なる役割を持つ。

同じ題材を別カテゴリーで再登場させ、`暗算 ⇄ 倍数判定 ⇄ 計算の工夫` の統合を教材そのもので体感できるようにする。
